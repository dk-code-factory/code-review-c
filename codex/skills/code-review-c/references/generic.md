# Other languages and project types

Adapt the evidence standard to the artifact. Trace changed callers, data flow,
supported builds, failure handling, and factual claims before reporting. For UI,
CLI, infrastructure, configuration, build tooling, and documentation, identify the
actual user or system contract and an observable violation. Load repository-specific
guidance through the controller; do not infer backend semantics for unrelated code.
Absent a meaningful specification, say it is unavailable rather than invent one.
